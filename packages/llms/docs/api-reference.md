# @razorwind/llms API

The default export and `generateLlms` live on `@razorwind/llms`. The plugin name is `llms:generate`. `renderLlmsIndex` and `renderLlmsDocuments` build the six strings before they are wrapped as documents. `fontAssetsUrl` falls back to the core config value.
