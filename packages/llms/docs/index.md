# llms.txt

The plugin writes six Markdown text files: `llms.txt`, `llms-tokens.txt`, `llms-components.txt`, `llms-icons.txt`, `llms-fonts.txt`, and `llms-guidelines.txt`. Set `outputPath` to put them in a directory. When you omit it, they are written in the generation directory.
