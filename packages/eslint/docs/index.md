# ESLint design-system rules

The plugin writes `eslint/design-system/index.mjs`. Rules cover token use and components from the schema. Tailwind guardrails are included by default. Tamagui guardrails are off until you pass `tamagui`. Generation is `combined`, so one file covers every theme.
