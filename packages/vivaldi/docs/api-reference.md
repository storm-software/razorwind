# @razorwind/vivaldi API

`vivaldi(options)` is the default export. `toVivaldiColor` formats a color. `generateVivaldiTheme` builds the documents.

Omit the options object and generate throws `@razorwind/vivaldi requires options: { mapTheme }`.
