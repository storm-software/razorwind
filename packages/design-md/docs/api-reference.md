# @razorwind/design-md API

`@razorwind/design-md/generate` exports `generateDesignMd`, `renderDesignMd`, and `extractDesignMd`. `@razorwind/design-md/extract` exports `parseDesignMdTokens` and `designMdToTokens`. Default front matter uses the name `Razorwind Design System` and version `alpha`.
