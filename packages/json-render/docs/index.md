# json-render catalog

The plugin writes `catalog.ts`, `catalog.schema.json`, `catalog.prompt.txt`, and `INSTALL.md` under `json-render`. `themeGeneration` is `combined`. `strict` defaults to true and rejects unknown fixed-shape fields in the schema.
