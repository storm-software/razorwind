# @razorwind/json-render API

`@razorwind/json-render` and `@razorwind/json-render/generate` export the default plugin, `generateJsonRender`, and `renderCatalogSource`. `createJsonRenderCatalog` and `createPropsSchema` live in the catalog module. `createJsonRenderJsonSchema` builds the JSON Schema.
