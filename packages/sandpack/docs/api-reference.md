# @razorwind/sandpack API

`sandpack(options)` is the default export of `@razorwind/sandpack`. `mapTheme` is required for theme files. `mapFiles` is optional and overrides automatic usage demos.

Omit the options object and generate throws `@razorwind/sandpack requires options: { mapTheme }`.
