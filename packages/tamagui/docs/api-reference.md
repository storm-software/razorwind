# @razorwind/tamagui API

The default export of `@razorwind/tamagui` writes the config. `@razorwind/tamagui/eslint` writes the guardrail module. `generateTamaguiConfig` and `renderTamaguiConfig` build the file. `toTamaguiValue` formats a token value.
