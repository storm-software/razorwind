# Tamagui config

The default plugin writes one `tamagui.config.ts`. Light and dark sets stay in that file. `themeGeneration` is `combined`. The default `target` is `v2`. Set `target` to `v3` for flat values. The ESLint subpath emits guardrails only for `v3`.
