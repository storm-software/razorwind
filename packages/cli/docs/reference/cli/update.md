# Update

A command for checking and updating the version of the Razorwind command-line interface application.

The `update` command can also be invoked using the alias `upgrade`.

## Usage

The `update` command can be executed using the following syntax:

<details>
<summary>Using npm:</summary>

```sh
npx razorwind update [options]
```

</details>

<details>
<summary>Using yarn:</summary>

```sh
yarn exec razorwind update [options]
```

</details>

<details>
<summary>Using pnpm:</summary>

```sh
pnpm exec razorwind update [options]
```

</details>

<details>
<summary>Using bun:</summary>

```sh
bun x razorwind update [options]
```

</details>
