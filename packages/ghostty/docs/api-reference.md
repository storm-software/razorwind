# @razorwind/ghostty API

`ghostty(options)` is the default export. `toGhosttyColor` normalizes a color string. `generateGhosttyTheme` builds the documents.

Omit the options object and generate throws `@razorwind/ghostty requires options: { mapTheme }`.
