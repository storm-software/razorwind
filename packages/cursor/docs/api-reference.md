# @razorwind/cursor API

`cursor(options)` is the default export of `@razorwind/cursor`. `generateCursorExtension` is the document builder. Default `version` is `0.0.1`. Default `license` is `Apache-2.0`. Default `engines.vscode` is `^1.85.0`. Default `categories` is `Themes`.

Omit the options object and generate throws `@razorwind/cursor requires options: { name, publisher, mapTheme }`.
