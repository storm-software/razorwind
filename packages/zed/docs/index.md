# Zed themes

The plugin writes an extension under `zed-extension`. `id` is required and must be a lowercase slug. The theme JSON schema defaults to `https://zed.dev/schema/themes/v0.2.0.json`. `schemaVersion` defaults to 1. `version` defaults to `0.0.1`.
