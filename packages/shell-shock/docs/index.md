# Shell Shock design system

The default export is a Razorwind generate plugin. It writes a theme file, `design-system.json`, and `INSTALL.md` under `shell-shock`. `@razorwind/shell-shock/plugin` is a Shell Shock plugin. It loads that snapshot and adds design-system commands.
