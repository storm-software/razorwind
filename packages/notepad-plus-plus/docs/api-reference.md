# @razorwind/notepad-plus-plus API

`npp(options)` in the package example is the default export of `@razorwind/notepad-plus-plus`. `toNppColor` formats a color. `generateNotepadPlusPlusTheme` builds the documents.

Omit the options object and generate throws `@razorwind/notepad-plus-plus requires options: { mapTheme }`.
