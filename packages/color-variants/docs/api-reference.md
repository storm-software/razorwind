# @razorwind/color-variants API

The package entry and `@razorwind/color-variants/extract` export the same plugin as the default. Named exports include `DEFAULT_COLOR_VARIANTS` and the `ColorVariant` type.

The extract hook returns the spec unchanged when `tokens` is empty.
