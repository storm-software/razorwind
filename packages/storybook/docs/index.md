# Storybook token docs

The plugin writes MDX under `storybook/tokens`. The sidebar prefix defaults to `Design Tokens`. `mapTheme` is optional. When you set it, every theme is written to `{outputPath}/theme.ts`. `mapTheme` receives the token tree, not a flat array.
