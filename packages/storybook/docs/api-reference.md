# @razorwind/storybook API

The default export is the plugin. `flattenTokens` and `resolveTokenSets` on this package walk tokens for the MDX blocks. `renderColorPaletteBlock`, `renderTypesetBlock`, and `renderTokenTableBlock` build the Storybook blocks. `formatTokenValue` and `toCssVar` format values.
