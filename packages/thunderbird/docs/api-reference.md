# @razorwind/thunderbird API

`thunderbird(options)` is the default export. `toThunderbirdRgbString` formats a color for the manifest. `generateThunderbirdTheme` builds the documents.

Omit the options object and generate throws `@razorwind/thunderbird requires options: { mapTheme }`.
